# Sidebar redesign decision

- Direction: A (grouped, coloured icons, status).
- Groups: Work (Notes, Connections, Todos), Data (DB Query, Ports, Vault), Utilities (Clipboard, Tools). Drag-reorder works within a group.
- Badges: Connections dot (red = re-auth, green = running...), Todos count (open overdue + due today), dim shortcut on the right (reads Settings shortcuts), bottom summary "N running · N re-auth" (click opens Connections).
