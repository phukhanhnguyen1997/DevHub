B · Rail + Split pane (khuyên dùng nếu hay đổi qua lại giữa các tool)

Cột trái trong Tools: danh sách tool theo nhóm + ô tìm + ★ ghim (luôn thấy, đổi tool 1 click, thay Picker dạng menu hiện tại). Bên phải: Input | Output cạnh nhau, thanh tuỳ chọn gọn trên đầu, Copy / Swap / Clear, tìm trong output có tô vàng.
