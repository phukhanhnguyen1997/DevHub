# Tools redesign decision

- Direction: B (left rail + Input | Output split).
- Pinning: right-click a tool in the rail (Pin to top / Unpin), stored in UserDefaults `pinnedTools`.
- Long output: scrolls inside its frame, with Copy. No collapse/wrap.
- Rail groups: Format, Encode, Generate, Time & text; search box filters tools.
- Added Paste / Clear / Swap (output -> input) and a size/lines status line.
