Notes redesign: 3 directions + suggested features

You had no specific ideas, so these are suggestions based on what Notes already has (pin, tags, outline, backlinks, wiki links, ⌘K, 4 editor modes). Same content in all three, only the structure changes.

A · Library (3 panes, Apple Notes / Bear style)

Sidebar of smart views + tags + folders, then a list grouped by date (Pinned / Today / Earlier) with snippet and tag chips, then the editor with a property line (tags, edited time, word count).

  • Best for: browsing lots of notes by tag or date.
  • Cost: three columns eat width; the editor is narrower.

Kafka reauth runbook

#kafka#runbook· Edited 2 min ago · 412 words

When the tunnel asks for re-authentication, run the command below and enter the work password.

gcloud compute start-iap-tunnel kafka-1 9092 --local-host-port=localhost:9092

If it keeps failing

Check [[AlloyDB proxy ports]] for port clashes, then restart the tunnel from Connections.

B · Workspace (tabs + inspector, VS Code / Obsidian style)

Slim jump list, multiple notes open as tabs, a right inspector (outline, linked from, links to, properties), status bar with word count and back/forward.

  • Best for: runbooks that cross-link each other and that you keep open side by side.
  • Cost: more chrome; inspector can be toggled off.

Pinned strip on top, a card grid with preview text, tag filter chips, toggle Gallery / List. Click a card to open the page full width, with a back button.

  • Best for: rediscovering notes visually.
  • Cost: slower to scan 100+ notes; editing is a separate full-screen page.
